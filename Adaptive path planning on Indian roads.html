    How it works

    See

    The vehicle needs to know where the road is drivable and where obstacles are and how they move. Here the simulator supplies that inside the faint cone in front of the vehicle, which is its sensor range. On a real vehicle a camera with object detection and road segmentation would.

    Plan

    A* searches a grid for the cheapest route. Cells near obstacles and potholes cost more, so the path bends around them. Adaptive mode also adds where each obstacle will be half a second from now, uses bigger margins for pedestrians and two-wheelers, and replans about five times a second.

    Protect

    When an obstacle is detected the vehicle reacts in steps: it slows gently and steers around it, brakes firmly if the gap keeps closing, and makes an emergency stop only as a last resort. Braking force is capped at each step so passengers are not thrown forward. The baseline never brakes.

    Try this comparison

    Set traffic to 10 and let Basic A* run for two minutes. Note the collisions. Switch to Adaptive: it restarts with the same starting traffic, so the comparison is fair. Change the safety margin and watch the trade between safety and trips completed.
